# frog-knight-vs-boss-fly

Created by **Rylan Saw** — a retro 16-bit arcade action game playable across **Mobile**, **PC**, and **Web** browsers.

## Author
- **Creator:** Rylan Saw

## Features
- **Pause Control:** Pause and resume gameplay anytime via the **PAUSE** button or `P` / `Escape` key.
- **Large Arcade Display:** Expanded wide-screen arcade display for clearer action on Mobile, PC, and Web.
- **Per-Item Skill Keys:** Each item type unlocks its own dedicated skill key (`1` / `H` for Heal, `2` / `S` for Shield, `3` / `W` for Sonic Wave, `4` / `T` for Thunder, `5` / `R` for Dragon Rage) plus a clickable slot on the deck.
- **Stage 1 -> Giant Boss Fly -> Small Spiders -> Giant Boss Spider:** Fight small flies for 50 seconds, defeat the Giant Boss Fly, battle waves of small spiders, and face the Giant Boss Spider.
